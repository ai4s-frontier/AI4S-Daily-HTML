## 🌄 "高原"最新洞察

### 科学通用底座
- **形式化理论正在剥离 Agent 自主性的虚假叙事** 国科大团队在《Annals of Data Science》发表的智能体能力周期表提出可证伪硬指标：自主性要求启动、目标与终止条件全内生。这一理论直接将目前依赖 Prompt 和外部 Harness 的所有大模型定标为控制维为零（C=0），表明当前频发的 Agent 越权行为属于无物理约束下的手段失控，而非具有自主意志的智能演化。

### 通用 AI
- **长程推理的技术焦点从增加测试算力转向剔除冗余思维** Fireworks 推出的 Ember-1 通过环境反馈后训练压缩 40% 的思考 Token，配合 Jev 等轻量级模型将对齐与语法判定成本压缩 98%，显露了推理模型的工程瓶颈。这使得 Agent 开发范式快速收敛为“快慢双系统”：由微型确定性模型充当亚毫秒级拦截器与路由，昂贵的大模型仅保留给核心长程推演，直接改写了部署成本结构。

### 3️⃣ 计算化学与分子机器学习：同行评议揭示 ML 预测分子激发能优势源于基准定义偏差

* **假阳性性能优势剖析**：开放同行评议平台 PREreview 公开针对分子吸收波长（$\lambda_{\max}$）预测算法的评估研究。分析指出，近年多篇文献声称机器学习（ML）模型在紫外-可见光谱预测上全面超越含时密度泛函理论（TD-DFT），其实质并非模型具备超越量子力学第一性原理的表征能力，而是基准数据集中目标标签定义不一致导致的虚假优势。
* **基准构建偏差修正**：计算化学基准常将文献报道的“溶剂相实测吸收峰”与纯理论计算的“气相垂直激发能”混同。当 ML 模型直接拟合包含溶剂效应和仪器展宽的实验值时，在传统统计指标上表现更优；一旦引入严格的外部独立验证集并对齐几何松弛物理参数，传统小样本 ML 的外推泛化能力迅速失效。
* **推动严谨科学基准构建**：该评议强调了在分子表征与激发态化学机器学习中建立高保真外部验证集的必要性，呼吁 AI4S 社区厘清“经验参数过拟合”与“物理规律习得”的界限，避免被不严谨的评估协议误导。

### Faster prompt lookup drafting in llama.cpp

63 pts · 10 comments · [jadidbourbaki.github.io](https://jadidbourbaki.github.io/blog/prompt-lookup-llama-cpp/)

**📌 内容总结**

- 作者通过对 llama.cpp 的 Prompt Lookup Decoding（N-gram 投机采样）进行系统性数据结构与算法重构，实现草稿阶段（Drafting）耗时大幅降低、内存减少多达 2.6 倍。
- HN 关注点:
  - 核心改动包括：修复嵌套 map 的按值传递拷贝问题；将低效的 `std::unordered_map` 替换为分段平坦哈希表 `ankerl::unordered_dense::segmented_map`。
  - 针对 64% 的 2-gram 仅有单一后续词的长尾分布，将内层 Map 扁平化为排序 `std::vector`，并消除二分查找分支预测开销。
  - 静态语料库采用 Daniel Lemire 的只读不可变映射 `constmap`；Lemire 进一步提出“先校验最高频词频阈值再遍历”的跳过优化，整体草稿吞吐加速最高达 140 倍。

**💬 讨论总结**

- **工程实现与最终吞吐**：讨论焦点之一在于该项加速在端到端推理中的实际收益。部分开发者询问草稿速度的大幅提升究竟能折算为最终端到端生成的多少 tokens/s 增益。
- **开源协作与代码库分歧**：作者因在 Reddit 等渠道公开表达与 llama.cpp 核心维护者的沟通摩擦，引发了关于开源协作礼仪的争议；也有声音认为 llama.cpp 积累的历史包袱较重，急需底层重构或独立硬分叉。
