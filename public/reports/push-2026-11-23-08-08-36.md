## 📰 今日Top热点

### 1️⃣ [持续跟踪] 黎曼猜想证明通过 Lean/Mathlib 形式化验证，社区进入“机器已验、人类待读”阶段

* **核心亮点**：Lean 与 Mathlib 社区确认 Anthropic 数学家 Levent Alpöge 与 Claude 合作完成的黎曼猜想 Lean 代码库通过形式化验证，175,187 个模块零报错编译，5 个核心定理仅依赖 Lean 标准公理。
* **前情提要**：11 月 20 日，Alpöge 发布约 1700 万行 Lean 代码，宣称与 Claude 完成黎曼猜想及面向 Dirichlet L 函数的广义黎曼猜想证明；随后 Lean FRO 与 Mathlib Initiative 发布联合声明确认其形式化正确性。
* **最新验证细节**：数十名独立验证者使用上百 GB 内存复现编译，逐字节核验 8322 个 Mathlib 文件与 378 个依赖缓存，导出证明文件哈希值一致；证明被剥离源码后导出为 61.6GB 纯数据文件，经 Rust 内核 `nanoda`、`lean4lean`、官方 `leanchecker` 与独立内核 `con-leche` 交叉核验。
* **等价路径交叉印证**：MIT 数学家 Andrew Sutherland 将证明与 Robin1984 形式化库拼接，在不直接使用黎曼 ζ 函数的条件下，跑通 Robin 不等式与 Lagarias 不等式的机器验证，为 ζ 函数定义本身提供另一道保险。
* **AI 参与验证工具链**：独立内核 `con-leche` 由 Claude 在 Lean FRO 工程师监督下编写，并带有形式化一致性证明；验证日志顶部显示整套核验流程仍由 Claude Code 驱动。
* **数学界反应**：菲尔兹奖得主 James Maynard 表示相信证明正确，但强调只有当人类理解其思想与整体框架后，成果才可能获得全面认可；陶哲轩称该证明可能调动朗兰兹纲领与算术几何的现代工具，消化需要时间。
* **实际影响**：形式化验证解决的是“证明是否逻辑有效”，不解决“人类是否理解为何成立”；数学研究流程正在被拆分为机器核查、人类翻译、社区再解释三个环节。

### 5️⃣ Nature：ECG 基础模型在运动员筛查中暴露域偏移

* **核心亮点**：Nature 数字医学研究评估 ECG-FM、HuBERT-ECG、ECGFounder 三个心电图基础模型，发现其在通用临床数据上表现较强，但在高水平运动员心电图中性能下降。
* **实验设置**：模型在 PhysioNet/CinC 2021 的 87,662 个样本上微调，并在 43 份由专家标注的高水平或国家队运动员心电图上测试。
* **关键结果**：模型在 PhysioNet/CinC 2021 测试集上达到 AUROC 0.97、AUPRC 0.57、灵敏度 0.89；但在运动员数据上性能下降，确认存在域偏移。
* **医学 AI 含义**：心电图基础模型不能默认从普通临床人群直接迁移到特殊生理人群；运动员筛查需要专门标注、专门评估和可能的领域适配。
🔗 [Nature 论文](https://www.nature.com/articles/s41746-026-03474-9)

### 6️⃣ 清华等发布 Mind2Act World：具身机器人评测从成功率转向失败归因

* **核心亮点**：清华大学 mmlab@SIGS 联合远行光年等 16 家机构发布 Mind2Act World，用 30 项任务、180 种配置把机器人“想”“做”“想与做协同”分开评测，并为失败回合生成诊断卡。
* **评测规模**：首批评测覆盖 9 个代表性系统、56,700 个仿真回合，包括 3 个 Agent、4 个 VLA 和 2 个 WAM。
* **核心结果**：表现最好的 Agent GPT-6 Astra 在 Mind 任务成功率为 52.7%，Act 任务为 39.0%，Mind2Act 任务仅为 12.0%；端到端策略在 Mind2Act 任务上最高为 3.6%。
* **失败归因**：InternW0 的 8,220 个失败回合中，761 个属于“前置条件未满足就行动”；GPT-6 Astra 的 589 个失败回合中，55.3% 的首个错误出在物理执行，且有 264 个回合在决策预算仍剩三分之一以上时主动停止；G0.5 最常见失败是抓取，1,324 个失败回合首个错误是没抓住或没抓稳。
* **成本与延迟**：若把推理时间计入真实运行，三个 Agent 平均每次调用需 11.0–35.6 秒，端到端策略一次动作预测为 77–488 毫秒；GPT-6 Astra 平均每个回合 API 费用为 25.13 美元。
* **AI4S 意义**：具身智能评测正从“哪个模型分数更高”转向“模型差在哪一步、应该补数据还是改工具链”，为机器人操作改进提供可执行清单。

### 7️⃣ 论文称语言模型可无训练改写自身权重，自我改进能力随规模涌现

* **核心亮点**：UIUC、CMU、Rutgers、Princeton、Stanford、Yale 等机构论文称，Qwen3.5-27B 可在没有梯度、没有重新训练、没有 teacher 或 reward model 的情况下，读取并改写自身权重，并在未见题目上提升准确率。
* **实验设定**：模型在一次会话中获得三样东西：自己的权重、自己练习题的答案与对错、运行自己的能力；它需要诊断错误、写代码修改权重、对比改前改后表现，并决定提交或撤回。
* **主要结果**：在 490 道未见题上，准确率从 57.2% 提升到 63.8%，提高 6.6 个百分点；连续八次会话中提交三次、撤回五次，准确率只升不降。
* **修复受损模型**：研究者复制模型并将一个权重矩阵的 8 行用噪声覆盖，模型自行测量 112 个矩阵，定位 Layer 30 的 `down_proj` 异常，并写入新数值；文本数学题从 0.0% 恢复到 33.0%，六个未见图像 benchmark 从 7.3% 恢复到 70.2%，达到未受损模型的 83%。
* **规模条件**：同一任务交给 2B、4B、9B、27B 四个尺寸，2B 未做任何改动，4B 和 9B 改坏自身，只有 27B 能先读懂再动手并按测试结果决定提交。
* **AI4S 意义**：该工作把“训练”和“推理”之间的边界推向更模糊的位置，显示模型可在低算力条件下进行局部自我修正；同时，自我改写、自我修复和递归改进也直接提高安全监控难度。
🔗 [PaperWeekly 解读](https://mp.weixin.qq.com/s?__biz=MzIwMTc4ODE0Mw==&mid=2247724047&idx=1&sn=0f7d52679594b122f1f23b720546bde7) | [arXiv 论文](https://arxiv.org/abs/2611.21885) | [项目主页](https://www.jiajunfan.com/projects/self-rewriting/)

### 8️⃣ MiniMax 称内部模型自动化破解多个前沿密码方案，理论攻击推进到可执行

* **核心亮点**：MiniMax 宣布其研究团队用最新内部模型对现代密码方案开展系统性自动化密码分析，发现多处未知算法构造缺陷，并将多个理论攻击推进到秒级至分钟级可执行破解。
* **三类进展**：针对历届 NIST 国际密码标准化竞赛，模型实际攻破多个此前“尚无已知实际攻击”的候选算法；针对近年顶会顶刊论文及竞赛优胜方案，模型实现高效密文伪造或密钥恢复，并刷新新型分组密码最高破解轮数纪录；在公钥密码基础困难问题求解中，模型结合隐含代数结构挖掘与系统级工程优化，攻克数十个尚无公开解的高阶挑战实例，相比当前最优算法实现数百至数万倍实测加速。
* **安全边界**：MiniMax 强调相关发现聚焦学术前沿方案、历史竞赛候选设计和公开参数挑战，不影响 AES、RSA、SHA-256 等现行主流密码标准。
* **披露方式**：团队已提前将结果同步给相关方案作者，并将模型生成的推理轨迹整理为技术报告和代码公开。
* **AI4S 意义**：密码分析长期依赖人类数学直觉与工程实现；若模型能稳定发现代数结构并生成可执行攻击路径，算法评估流程需要加入 AI 红队测试。
