### 1️⃣ Anthropic 发布 Claude Fable 5.1 与 Mythos 5.1：科研基准翻倍，缓存读取降价 75%

* **自主科研基准飞跃**：在衡量 AI 智能体自主科研能力的 Terminal-Bench-Science 0.1 基准上，Fable 5.1 得分达 52.6%（前代 Fable 5 仅为 24.7%）；在 Terminal-Bench 4.0 编程测试中得分 55.8%（Mythos 5.1 达到 60.9%）。
* **AI4S 实例验证**：Anthropic 展示了利用 NASA 麦哲伦雷达数据将金星地形分辨率提升至 2–3 公里的神经网络成果；在生物学测试中，Mythos 5.1 辅助设计的结合物在三个靶点上的亲和力比竞赛最佳基准提高 10 倍，并为 7 个深度学习模型重写 GPU 算子，降低全基因组分析成本 30%–60%。
* **成本与数据合规重构**：输入输出价格维持不变，但上下文缓存读取（Prompt Cache Read）单价下调 75% 至 $0.25/MTok；同步推出 Enterprise Frontier Safeguards（EFS），支持企业数据完全保留在自身云存储内并进行自动化安全监控。

### 3️⃣ 哈佛与 St. Jude 等机构开源 AdaptiveFlow：将百亿级分子虚拟筛选算力成本降低 1000 倍

* **技术突破**：来自 St. Jude 儿童研究医院、哈佛医学院、Dana-Farber 癌症研究所及帕维亚大学的联合团队在《Nature Biotechnology》发表最新成果，正式开源药物发现计算平台 AdaptiveFlow。

* **科研意义**：该工具消除了以往超大型化学库虚拟筛选对顶级超算集群的严苛依赖，使高通量先导化合物发现能够常规化部署在通用云算力平台上。

### Claude Fable 5.1 and Claude Mythos 5.1

850 pts · 813 comments · [anthropic.com](https://www.anthropic.com/claude-fable-and-mythos-5-1)

**📌 内容总结**

- Anthropic 发布新一代前沿模型 Claude Fable 5.1 及对应高权限版本 Mythos 5.1（同模型权重，面向经过审核的网络安全与生物科研项目开放更宽松的拦截策略）。
- HN 关注点:
  - **定价与缓存优化**：Token 基础调用单价维持不变（输入 $10/M、输出 $50/M），但 Cache Read（缓存读取）成本直降 75% 至 $0.25/M。高频上下文复用的 Agent 类任务端到端成本降低约 25%–45%。
  - **合规与防蒸馏限制**：新增企业级零数据留存机制（EFS，数据仅存用户云端）；新增符合欧盟 AI 法案的不可见文本水印检测 API；API 引入防蒸馏机制，禁止新账户在保留思维链（thinking blocks）的同时篡改历史上下文。
  - **基准表现**：在 Terminal-Bench-Science 0.1 上准确率从 24.7% 提升至 52.6%；网络安全拦截误报率降低 60%，允许用于防御侧漏洞分析。

**💬 讨论总结**

- **缓存降价受认可，但总体成本仍高**：开发者认可大幅削减 Cache Read 价格对长上下文 Agent 的实用价值（有团队实测总成本下降约 30%），但认为在开源及高性价比模型（如 DeepSeek、Gemini Flash）竞争下，基础 Token 单价依旧昂贵。
- **上下文锁定引发工程吐槽**：为防止思维链被竞品蒸馏，Anthropic 将 API 上下文改为只读追加（Append-only），禁止动态修改 System Prompt 或多轮重构上下文。多位工程师批评此举为高侵入性的“模型 DRM”，严重破坏定制化 Agent 框架。
- **安全过滤与降级机制争议**：大量用户反映虽然官方宣称降低了误报率，但普通版本在处理网络安全和复杂编程任务时仍极易误触防御机制，并静默降级为旧版 Opus；即便是安全审计计划内的团队也常受此困扰。
- **基准增幅被指出现边际递减**：部分分析指出，除特定科学基准外，常规代码与通用推理基准较 Opus 5 提升幅度仅在个位数百分比，引发关于前沿大模型性能爬坡是否放缓的讨论。

### Atlas: A World Model for Spatial Intelligence

132 pts · 25 comments · [worldlabs.ai](https://www.worldlabs.ai/blog/atlas)

**📌 内容总结**

- 李飞飞联合创立的 World Labs 发布通用世界模型 Atlas，旨在通过文本、图像、视频与 3D 深度联合建模实现空间智能。
- HN 关注点:
  - **架构设计**：采用自回归扩散 Transformer（Autoregressive Diffusion Transformer），将所有输入投影并锚定在统一的三维空间上下文中，支持原生相机位姿输入与 3D 深度图处理。
  - **核心能力**：支持像素级精度的相机轨迹控制与新视角生成；支持从极少数（1-3 张）稀疏照片重建稠密 3D 点云与 3D 高斯泼溅（3D Gaussian Splats）；支持生成长达 1 分钟、1440p 的长视频。
  - **Real-to-Sim 机器人应用**：可从普通手机拍摄的视频中提取环境与物体交互，生成机器人本体传感器视角的 RGB 及深度流，用于机器人导航与操作模拟。

**💬 讨论总结**

- **稀疏重建能力获高度评价**：多位计算机视觉从业者认为从几张手机照片直接生成高几何一致性的 3DGS 场景是目前最实用的突破，能够极大降低游戏地图原型设计、影视特效与环境扫描的工程门槛。
- **空间一致性 vs 时间物理动态**：有讨论指出 Atlas 目前长于空间几何的稳定推演（运镜时场景结构不崩塌），但在动态物理模拟上仍多以静态/冻结时间视差为主，真实动态物理交互的长期一致性仍有待提升。
- **潜在语义价值挖掘**：开发者提出世界模型不仅应停留在“生成渲染视图”，其模型隐空间（Latent Space）中内生的可通行区域识别（如地板、障碍物判定）等 3D 空间语义，对机器人路径规划具备直接复用价值。
